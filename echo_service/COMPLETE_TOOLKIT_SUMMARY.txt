================================================================================
                          HOW THE EXPLOIT WORKS
================================================================================

VULNERABILITY: Buffer Overflow in vuln() function

EXPLOITATION FLOW:
  1. Connect to the service
  2. Service prompts for input with "> "
  3. Send payload: [PADDING] + [read_flag ADDRESS]
  4. Overflow overwrites the return address
  5. Function returns to read_flag() instead of caller
  6. read_flag() opens "./flag" and prints the contents
  7. Receive the flag!

REQUIRED PARAMETERS:
  • Offset: Number of bytes to reach return address (32-72 typical)
  • Address: Memory location of read_flag() function (0x08048xxx typical)

                            KEY INFORMATION
================================================================================

BINARY TYPE: 32-bit ELF executable
ARCHITECTURE: x86 (little-endian)
KNOWN FUNCTIONS:
  • main()      - Entry point
  • vuln()      - Contains buffer overflow vulnerability
  • read_flag() - Target function that reads the flag

KNOWN STRINGS:
  • "./flag"           - Flag file path
  • "ECHO SERVICE"     - Service banner
  • "> "               - Input prompt
  • "Invalid command:" - Error message

LIBC FUNCTIONS USED:
  • fgets/read  - Input (potentially vulnerable)
  • fopen       - Opens flag file
  • puts/printf - Displays output
